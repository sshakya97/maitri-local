# Maitri Team Jira Dashboard

Real-data dashboard for ACT + CONN projects — Anjali, Sanabul, Sashank, Buddhi Sagar.

## Run locally

```bash
npm install
npm run dev
```

Then open → http://localhost:5173

## Features
- Board view (grouped by status) + Table view
- Filter by person, project (ACT / CONN), status
- Sort by updated / priority / status
- Click any card → see the latest Jira comment
- Light / Dark mode toggle
- Ticket keys link directly to macrohealth.atlassian.net
